Jenkins

    Основные понятия

  • Job — отдельный проект или процесс, который настраивается в Jenkins (например, сборка конкретного приложения).
  • Pipeline — сценарий, который описывает всю цепочку действий (от скачивания кода до деплоя) в виде кода.
  • Jenkinsfile — текстовый файл в репозитории, в котором записывается вся логика пайплайна.
  • Build — один конкретный запуск задачи. Каждый запуск имеет свой номер (например, Build #12).

    • Ключевые элементы интерфейса

  • Workspace (Рабочая область) — временная папка на агенте, куда Jenkins скачивает код для выполнения текущей задачи.
  • Console Output (Вывод консоли) — логи выполнения задачи. Главное место для поиска ошибок, если сборка сломалась.
  • Plugins (Плагины) — дополнения, которые расширяют возможности Jenkins.
