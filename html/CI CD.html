CI/CD

    Этапы автоматизации

  • BUILD (Сборка) — компиляция кода и создание готового продукта (например, Docker-образа).
  • TEST (Тестирование) — автоматический запуск тестов для проверки ошибок в коде.
  • RELEASE (Релиз) — подготовка проверенной версии программы к отправке.
  • DEPLOY (Развертывание) — публикация программы на рабочие сервера для пользователей.

    • Базовые термины

  • Pipeline (Пайплайн) — цепочка шагов от сборки кода до его запуска на сервере.
  • Artifact (Артефакт) — готовый файл (результат сборки), который отправляется на сервер.
  • Runner (Раннер) — сервер или программа, которая выполняет команды пайплайна.
