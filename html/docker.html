Docker

    Управление контейнерами (Запуск и остановка)

  • docker run — создание и запуск нового контейнера из образа.
  • docker stop — остановка одного или нескольких работающих контейнеров.
  • docker start — запуск одного или нескольких ранее остановленных контейнеров.
  • docker restart — перезапуск контейнера.
  • docker rm — расшифровывается как "Remove". Удаляет один или несколько остановленных контейнеров.
