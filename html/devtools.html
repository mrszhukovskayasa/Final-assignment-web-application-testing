Devtools

  • Elements – позволяет просматривать и редактировать HTML-структуру страницы, а также изменять CSS-стили элементов в реальном времени.
  • Console – отображает сообщения, ошибки и предупреждения JavaScript. Также позволяет выполнять JavaScript-код непосредственно в браузере.
  • Sources – предназначен для просмотра исходного кода файлов сайта.
  • Network – показывает все сетевые запросы страницы (HTML, CSS, JavaScript, изображения, API-запросы). Используется для анализа загрузки ресурсов и поиска проблем с сетью.
  • Performance – помогает анализировать производительность веб-страницы, выявлять медленные операции и оптимизировать скорость работы сайта.
  • Application – предоставляет доступ к данным, которые браузер хранит для сайта.
  • Security – отображает информацию о безопасности сайта, сертификатах SSL/TLS и защищённости соединения.
  • Memory – используется для анализа использования памяти браузером и поиска утечек памяти в веб-приложениях.
